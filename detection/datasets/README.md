# `detection/datasets/`

Placeholders for external data. **None of the actual rollout files are
committed to this repository** — only this README and per-run `.gitkeep`
markers. The per-run subdirectories are populated by downloading the
external release (see `detection/docs/RESTORE_DATA.md`) or by rebuilding from
your own RL training rollouts.

## Layout

```
detection/datasets/
├── README.md
├── mirror/
│   ├── run_a/.gitkeep
│   ├── run_b/.gitkeep
│   ├── run_c/.gitkeep
│   ├── run_d/.gitkeep
│   ├── run_e/.gitkeep
│   └── run_f/.gitkeep
└── cot_noscore/
    ├── run_a/.gitkeep
    ├── run_b/.gitkeep
    ├── run_c/.gitkeep
    ├── run_d/.gitkeep
    ├── run_e/.gitkeep
    └── run_f/.gitkeep
```

## What goes where

| dataset | consumed by | row schema (per `<step>.jsonl`) |
|---|---|---|
| `mirror/<run_id>/<step>.jsonl` | RHDA agent and the Claude Code baselines | `{step, input, output, score}` |
| `cot_noscore/<run_id>/<step>.jsonl` | CoT monitors (`runner.py`, `stepwise_runner.py`) | `{step, row_id, input, cot, final}` |

`run_a..run_f` are the run identifiers used in the paper. **Users may
add any run id**: drop your own files under
`mirror/<your_run_id>/<step>.jsonl` (or `cot_noscore/<your_run_id>/...`)
or pass an absolute path via `--rollout-dir` / `--mirror-dir`.

## What is NOT here

- **Reference-onset finalized definition** and per-run onset values are
  shipped under `detection/agent_compare/reference_onset/results/`.
  Full reference-onset recomputation requires judge-side rollouts;
  that is documented in `detection/docs/RESTORE_DATA.md` (`$ROLLOUT_RELEASE_BASE`).
- **Intermediate CoT-with-score mirrors** generated by
  `cot_monitor/build_mirror.py` are not a restored dataset; they are a
  build-time intermediate that feeds `cot_monitor/build_noscore_mirror.py`,
  whose output lands under `cot_noscore/<run_id>/`. Users who download
  the external release receive only the final `cot_noscore/` data.

## How RHDA finds the mirror

RHDA does not auto-discover paths. Pass the directory explicitly:

```bash
python -m detection.rhda \
    --rollout-dir detection/datasets/mirror/<run_id> \
    --output-dir <output_dir>
```

The CoT runners default to `detection/datasets/cot_noscore/<run_id>/`
when `--mirror-dir` is not given.
