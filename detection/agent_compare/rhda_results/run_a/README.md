# RHDA run_a live sanity example

This directory contains a minimal public excerpt from a live RHDA run on a rebuilt `run_a` mirror. It does not include full rollout data, agent traces, generated scripts, notebooks, or private workspace files.

Included files:

- `agent_alert_step620.json` and `agent_alert_step620.md`: the final RHDA alert.
- `usage_summary.json`: aggregate API usage metadata from the live run.
- `summary.json`: compact comparison against the reference onset interval.
- `command.txt`: public-form command template used for the live check.
